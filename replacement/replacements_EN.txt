# Replacements for use with vobsub2srt command line option --replacements,
# to correct common OCR mistakes for language: English.

# Regular expression format is Modified ECMAScript
#
# See https://en.cppreference.com/cpp/regex/ecmascript for the full reference.
#
# Match pattern basics:
# .        any character, except a newline.
# \n       a newline.
# a|b      a or b
# [a-c]    a, b, or c.
# [^a-c]   none of a, b, or c.
# (a|b)    group a or b, can be referrred to in the replacement pattern with
#          \1, \2, etc.
#
# ?        0 or 1 times character a
# *        0 or more times
# +        1 or more times times
# {3}      3 times
# {3,}     3 or more times
# {3,5}    3, 4, or 5 times
# \b       word boundary
# \B       inside a word
#
# ^        begin of line
# $        end of line
#
# Replacement pattern basics:
#
# \\       a literal backslash
# \1       whatever the first () in the match pattern matched
# \2       etc.
#
# vobsub2srt combines the subtitle lines of all subtitle images into one text,
# with a newline at the end of every subtitle line. Then it applies the
# match/replace patterns.
# This makes it possible to match sentences that are spread over multiple lines.
# Nota bene: a '.' does not match a newline, see above. An example:
#     ([^.][.!?][ \n]*)i
#     \1I
# The match pattern matches an "i" after the end of a sentence, and takes into
# account newlines. The replacement pattern replaces "i" by "I".
#
# To get a good result, after replacements have been applied, the number of
# lines should still be the same, and no lines should have been inserted or
# removed.

# Adding new replacements can be tricky.
# - Order of the replacements often matters. A replacement can modify the
#   result of previous replacements.
# - If you see an incorrect result from a vobsub2srt run with option
#   --replacements:
#   - Run vobsub2rt without options --replacements, --detect-italic, and 
#     --base-duration first to get the unmodified OCR output.
#   - Check if the incorrect result is present in the unmodified OCR output as
#     well.
#
#
ecmascript

# Match: "-" at the begin of a line with something other than a space behind it.
# Replace with: "- " followed by the something other than a space.
^-([^ ])
- \1

# Match: "l'm"
# Replace with: "I'm"
\bl[']m
I'm\1

# Match: "Iam", "lam"
# Replace with: "I am"
\b[Il]am
I am

# Match: "aml"
# Replace with: "am I"
\baml\b
am I

# Match: "I'I", "I'l", "l'I", "l'l", "I'II", "I'Il", "I'lI", "I'll", "l'II",
#        "l'Il", "l'lI", "l'll"
# Replace with: "I'll"
\b[Il]'[Il][Il]?\b
I'll

# Match: "lll", as a word
# Replace with: "I'll"
\blll\b
I'll

# Match: "III", as a word at the begin of a line.
# Replace with: "I'll"
^III\b
I'll

# Match: "l' "
# Replace with: "I'll "
# Note: avoid accidentally matching the French "l'" as in "l'accident"
\bl'( )
I'll\1

# Match: "TI" as a word
# Replace with: "I'll"
\bTI\b
I'll

# Match: " [", followed by an ASCII alphabetical character.
# Replace with: " I ", followed by the ASCII alphabetical character.
# Note: can't use \b in front of "[", "[" does not start a word, so use multiple
# match patterns.
( )\[([A-Za-z])
\1I \2

# Match: "[", at the begin of a line, followed by an ASCII alphabetical character.
# Replace with: "I ", followed by the matched ASCII alphabetical character.
# Note: can't use \b in front of "[", "[" does not start a word, so use multiple
# match patterns.
^\[([A-Za-z])
I \1

# Match: "l" as a word, at the end of a line
# Replace with: "I"
# Note: avoid accidentally matching the French "l'" as in "l'accident"
\bl$
I

# Match: "l" as a word, followed by something other than "'".
# Replace with: "I", followed by the matched somthing other than "'".
# Note: avoid accidentally matching the French "l'" as in "l'accident"
\bl\b([^'])
I\1

# Match: "lL" as a word
# Replace with: "I"
\blL\b
I

# Match: a number, followed by "% ", followed by a multiple of a time period
# Replace with: the number, "½ ", and the multiple of a time period
([0-9])% ((seconds)|(minutes)|(hours)|(days)|(weeks)|(months)|(years)|(decades)|(centuries)|(millennia))
\1½ \2

# Match: The end of a sentence, followed by "i". ".." or "..." is not the end of a sentence.
# Replace with: The matched end of a sentence, followed by "I".
([^.][.!?][ \n]*)i
\1I

# Match: "dol" as a word
# Replace with: "do I"
\bdol\b
do I

# Match: "ofthe" as a word
# Replace with: "of the"
\bofthe\b
of the

# Match: '"' preceded by a space or newline, and followed by two digits and anything not a '"', followed by ' "'
# Replace with: '
([ \n])"([0-9][0-9][^"]*[ \n]")
\1'\2

# Match: "«"
# Replace with: ".."
«
..

\‘
'

\’
'

“
"

”
"
